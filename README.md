# 家計簿アプリ（プロトタイプ）

`docs/家計簿アプリ_実装プロンプト.md`（Draft 1.2の要件定義書に基づく）から生成した、個人用家計簿アプリのプロトタイプです。

- `Code.gs` … データ保存先（Googleスプレッドシート）を操作するAPI本体（Google Apps Script）
- `index.html` … スマホ・PCのブラウザで使う画面本体（PWA）
- `manifest.json` … スマホのホーム画面に追加するための設定ファイル
- `icons/` … ホーム画面アイコン（仮のプレースホルダー画像です。お好きな画像に差し替えてOKです）

構成のイメージ：スマホの `index.html`（画面） ↔（インターネット経由でデータの読み書き）↔ Google Apps Script（`Code.gs`） ↔ Googleスプレッドシート（データの保管場所）

---

## 1. Googleスプレッドシートを準備する

1. [Googleスプレッドシート](https://sheets.new) を開き、新しいスプレッドシートを1つ作成する（名前は「家計簿」など好きな名前でOK）
2. メニューの **拡張機能 → Apps Script** をクリックする（別タブでスクリプトエディタが開きます）

## 2. Apps Scriptにコードを貼り付ける

1. スクリプトエディタに最初から入っている `myFunction` などのコード（`Code.gs` の中身）を全部消す
2. このフォルダの `Code.gs` の中身を全部コピーして貼り付ける
3. 上部の保存アイコン（またはCmd+S）で保存する。プロジェクト名を聞かれたら「家計簿アプリ」などにする

## 2.5 （推奨）Sheets APIを有効にして速度を上げる

シートを1枚ずつ読みに行く回数を減らし、起動や保存を速くするための追加設定です（必須ではありませんが、設定しないと動作が遅いままになります）。

1. スクリプトエディタ左側メニューの「サービス」の横にある **＋** をクリック
2. 一覧から **Google Sheets API** を選び、**追加** をクリック
3. 特に設定は不要です。追加できていれば完了です

> 補足：この設定をしなくてもアプリ自体は正常に動きます（自動的に従来通りの遅い方法にフォールバックします）。設定後は改めて「デプロイ → デプロイを管理 → 新しいバージョン」でデプロイし直してください。

## 3. Webアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ** をクリック
2. 歯車アイコンから種類を選ぶ画面で **ウェブアプリ** を選択
3. 設定内容
   - 説明：任意（例：v1）
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
     - 「自分のみ」にすると、`index.html`からのデータ取得（fetch通信）がGoogleへのログイン情報をうまく引き継げず、「誰が」「支払い方法」やカテゴリが表示されない・通信エラーになることがあります
     - 「全員」にしても、実行するプログラムは常に自分（デプロイした本人）の権限で動くため、自分のスプレッドシート以外は操作されません。実質的な保護はURL自体の推測されにくさ（長いランダムな文字列）によるものです。他人に共有しない限り安全です
4. **デプロイ** をクリックすると、Googleアカウントへのアクセス許可を求める画面が出るので、自分のアカウントを選んで許可する
   - 「このアプリは確認されていません」という警告が出た場合は、**詳細** →「（プロジェクト名）に移動」で進めて問題ありません（自分だけが使う自作アプリのため）
   - デプロイ設定（アクセス権限など）を変更した直後は、反映まで数十秒〜数分かかることがあります。変更してすぐ通信エラーになる場合は、少し時間を置いてから`index.html`を再読み込みしてみてください
5. デプロイが完了すると **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxxx/exec` のような形）が表示されるので、コピーしておく

> 補足：`Code.gs` を保存し直した後にコードを更新した場合は、もう一度「デプロイ → デプロイを管理 → 編集（鉛筆アイコン）→ 新しいバージョン」を選んでデプロイし直す必要があります（URLは変わりません）。

## 4. アプリ側にURLを設定する

1. `index.html` をブラウザで開く（ダブルクリックでOK）
2. 初回は自動で「設定」画面の「接続設定（データ保存先）」が開くので、手順3でコピーしたURLを貼り付けて保存する
3. 保存すると自動で読み込み直され、初期カテゴリ（食費・家賃など）やメンバー（パパ・ママ）が表示されれば成功です

初期データ（カテゴリ・メンバー・支払い方法など）は、初回アクセス時にApps Script側で自動的にスプレッドシートへ作成されます。

## 5. スマホのホーム画面に追加する（アプリのように使う）

`index.html` をそのままローカルファイルとして使うこともできますが、スマホのホーム画面に追加してアプリのように起動するには、`index.html` をインターネット上のどこか（自分専用の非公開ページでOK）に置く必要があります。

おすすめは **GitHub Pages**（無料・院内Windows/Mac両方から更新可能）です。CLAUDE.mdの方針に沿って、プロトタイプ段階からGitで管理する場合は、そのままGitHub Pagesとして公開する流れがスムーズです。この手順は、Gitリポジトリの準備ができた段階で改めてご案内します。

ホスティング後の手順：
1. スマホのブラウザ（iOS Safariなど）でそのURLを開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動すると、ブラウザのアドレスバーなどが無い、アプリのような見た目で使えます

## 6. データを直接確認・修正したいとき

手順1で作成したGoogleスプレッドシートを直接開けば、`取引` `カテゴリ` `メンバー` `支払い方法` `固定費` `月次予算` `設定` の7つのシートに保存された内容をいつでも確認・修正できます（バックアップも兼ねています）。

## 今回のプロトタイプでできること

要件定義書（Draft 1.2）の主要機能を一通り実装しています。

- 入力画面：誰が→支払い方法→支出/収入→金額（テンキー）→カテゴリの順でタップし、カテゴリを選んだ瞬間に保存
- 今月の収支（残高／使える残高）のワンタップ切り替え、今月の予算（ざっくり）バー表示・週別内訳オーバーレイ
- 固定費の自動更新（対応するカテゴリ×誰がの支出を記録すると、自動更新ONの固定費金額に反映）
- 履歴・一覧画面（月送り、カテゴリ／誰が／支払い方法での絞り込み、キーワード検索、編集・削除）
- 集計・グラフ画面（前月比、カテゴリ別／メンバー別／支払い方法別の円グラフ、日別支出の棒グラフ）
- 設定画面（カテゴリ・予算、固定費、メンバー、支払い方法、締め日）

## スコープ外（未実装・今後の検討事項）

要件定義書の「9. 今後の検討事項」「実装プロンプト 8. スコープ外」と同様、以下は今回のプロトタイプに含んでいません。

- オフライン時の入力対応（一時保存→オンライン復帰時の同期）
- 予算超過等の通知機能
- 家族共有・複数アカウントでの利用
- CSVエクスポート

## 既知の制約

- ホーム画面アイコン（`icons/icon-192.png` / `icon-512.png`）はコード生成時に用意した仮のプレースホルダー画像です。お好みの画像があれば、同じファイル名で差し替えてください
- Apps Script Webアプリはコールドスタート時にやや時間がかかることがあります（体感1秒を超える場合があります）。実運用で気になる場合は改めて調整可能です
