# 家計簿アプリ 開発開始ガイド（VS Code + Claude Code）

ここまでで固まった要件定義書・実装プロンプトを使って、VS Codeでの実装に移るための準備手順です。

## 1. プロジェクトフォルダを作る

ローカルに作業用フォルダを作成し、その中に `docs` フォルダを作って以下2つのファイルを入れておきます。

```
kakeibo-app/
└── docs/
    ├── 家計簿アプリ_要件定義書.md
    └── 家計簿アプリ_実装プロンプト.md
```

（この2ファイルはこの会話からダウンロードできます）

## 2. VS Codeでフォルダを開く

`kakeibo-app` フォルダをVS Codeで開きます。

## 3. Claude Code拡張機能を準備する

VS Code内でClaude Codeを使う場合は、拡張機能をインストールしてサインインしてください（下に案内カードを表示します）。

## 4. Claude Codeに実装を依頼する

Claude Codeのチャットを開き、次のように依頼すると実装プロンプトの内容がそのまま伝わります。

```
docs/家計簿アプリ_実装プロンプト.md の内容に従って、家計簿アプリを実装してください。
```

Claude Codeがファイルを読み込み、`Code.gs` / `index.html` / `manifest.json` / `README.md` を生成していく流れになります。実装中に仕様の解釈で迷った場合は、同じフォルダ内の `家計簿アプリ_要件定義書.md` を参照してもらうと判断しやすくなります。

## 5. Googleスプレッドシート側の準備（実装と並行でOK）

Apps Script + スプレッドシート構成なので、以下も併せて準備しておくとスムーズです。

- Googleスプレッドシートを1つ新規作成しておく（シート自体はApps Script側の初期化処理で自動構成される想定ですが、空のファイルは事前に用意しておくと迷いません）
- スプレッドシートの「拡張機能」→「Apps Script」からスクリプトエディタを開けることを確認しておく
- Apps ScriptをWebアプリとしてデプロイする際に必要な「デプロイ」→「新しいデプロイ」の操作は、実装がある程度進んだ段階でClaude Codeと一緒に行うとスムーズです

## 6. 実装が進んだら

要件定義書は「仕様の正」として、実装中に仕様変更や追加要望が出た場合は都度更新していくと、後から見返したときに経緯が分かりやすくなります。
